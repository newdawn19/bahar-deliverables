# 03 · 业务配置与接入清单

> **本文档目的**：列出客户在采购 / 部署 bahar 四行业矩阵站之后，**需要自行向第三方申请或在本系统中完成配置**的外部接入项与基础业务数据，便于实施排期与责任分工。所有配置项均可在源码中核对（`common/bean/*`、`common/enums/SmsSettingEnum.java`、`common/config/*`、各 `application.yaml`）。

> ⚠️ **重要前提（务必先读）**：当前仓库随附的四份 `application.yaml`（零售 8081 / 汽车 8082 / 餐饮 8083 / 康养 8084）**仅内置了 `spring`、`aliyun.oss`（本地磁盘模式 `mode=0`）、`images`、`server` 等基础段**，并不包含 `wxpay` / `alipay` / `v3` / `union` / `weixin.*` / `aliyun.sms.*` 等支付与短信凭证段。代码中这些密钥通过 `env.getProperty("weixin.pay.appId")` 或 `@ConfigurationProperties(prefix=...)` 从 **Spring 环境（yaml / 环境变量 / 配置中心）** 读取。因此上线前需由客户按下方「配置位置」补充对应配置段，或在运维侧注入环境变量（`ALIYUN_SMS_MODE` 等 Spring 宽松绑定写法）。

## 一、外部接入配置清单

| # | 配置项 | 用途 | 必填 / 选填 | 配置位置（yaml / 后台 / 数据库） | 缺失后果 | 申请渠道 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | **短信服务商**（账号 / 密钥 / 签名 / 模板） | 发送登录验证码、核销通知等 | 选填（演示可关） | ① 全局：`aliyun.sms.mode / accessKeyId / accessKeySecret / signName`（env 读取）<br>② 商户级：`mt_setting` 中 `type=SMS_CONFIG`，`name` ∈ {`isClose`,`accessKeyId`,`accessKeySecret`,`signName`}（`SmsSettingEnum`）<br>③ 模板：`mt_sms_template`（如 `login-code`、`confirm-coupon`，需启用） | 不配置则短信不下发；若 `isClose=1` 且未配密钥，登录验证码无法发送，仅演示环境可用 | 阿里云短信服务（或同类）控制台申请 AccessKey、签名、模板 |
| 2 | **微信支付（V2）** | 会员端微信 JSAPI / 刷卡 / H5 收款 | 必填（启用微信支付时） | ① 平台级：`wxpay.appId / appSecret / mchId / apiV2 / certPath / domain`（`WxPayBean`）<br>② 商户级：`mt_merchant.wx_app_id / wx_app_secret / wx_mch_id / wx_api_v2`（可在后台按商户覆盖）<br>③ 门店级：`mt_store.wx_mch_id / wx_api_v2 / wx_cert_path` | 未配置则微信收款失败，`createPrepayOrder` 无法统一下单 | 微信支付商户平台（mchid、APIv2 密钥、API 证书） |
| 3 | **微信支付 V3** | 新接口 / 部分能力（证书化） | 选填 | `v3.appId / keyPath / certPath / certP12Path / platformCertPath / mchId / apiKey / apiKey3 / domain`（`WxPayV3Bean`） | 仅在使用 V3 能力时影响；当前主干走 V2，缺失不影响基础收款 | 微信支付商户平台（V3 密钥、平台证书） |
| 4 | **支付宝** | 支付宝扫码 / 手机网站收款 | 选填（启用支付宝时） | `alipay.appId / privateKey / publicKey / appCertPath / aliPayCertPath / aliPayRootCertPath / serverUrl / domain`（`AliPayBean`） | 未配置则 `alipayService.createPrepayOrder` 失败，支付宝通道不可用 | 支付宝开放平台（创建应用、获取 appId、应用公钥 / 私钥、证书） |
| 5 | **银联 / 云闪付** | 银联收款 | 选填 | `union.machId / key / serverUrl / domain`（`UnionPayBean`） | 未配置则 `unionPayService` 通道不可用 | 银联开放平台 / 云闪付商户入驻 |
| 6 | **微信公众平台 / 开放平台 appId** | 会员端微信授权登录、unionid 多端打通 | 必填（启用微信登录时） | ① 公众号：`weixin.official.appId / appSecret`（`WeixinService.getWxOpenId`）<br>② 小程序：`wxpay.appId / appSecret`（`getWxProfile` / `getAccessToken`）<br>③ 商户级覆盖：`mt_merchant.wxOfficialAppId / wxOfficialAppSecret / wxAppId / wxAppSecret`<br>④ **unionid 打通**：需将上述公众号、小程序、App 绑定到同一微信开放平台账号 | 未配置则微信授权登录、获取手机号、订阅消息、小程序发货信息上传均失败 | 微信公众平台（服务号）、微信开放平台（绑定同主体） |
| 7 | **对象存储 OSS** | 图片 / 文件上传（头像、商品图、二维码等） | 选填 | ① `aliyun.oss.mode`（0=本地磁盘，1=阿里云 OSS）<br>② 启用 OSS 时：`endpoint / accessKeyId / accessKeySecret / bucketName / folder / domain` | `mode=0` 时落本地磁盘（`images.root`），无需 OSS；`mode=1` 未配则上传失败 | 阿里云 OSS 控制台（Bucket、AccessKey、域名） |
| 8 | **图片访问域名** | 拼接上传文件对外可访问 URL | 必填（对外访问） | `images.upload.url`（`${IMAGE_BASE_URL}`，默认各端 `http://127.0.0.1:8081~8084`） | 域名不正确则前端图片 404 | 自有域名 / 反向代理（Nginx） |
| 9 | **本地磁盘落盘根目录** | `mode=0` 时文件实际存储路径 | 必填（OSS 关闭时） | `images.root`（`${IMAGE_ROOT}`，如 `D:/oss/bahar-shop/`）、`images.path=/static/uploadFiles/` | 路径不存在或无写权限则上传失败 | 服务器本地磁盘 / 挂载盘 |
| 10 | **图形验证码** | 后台登录、注册人机校验 | 内置（默认开） | `CaptchaConfig` 读取 `captcha-conf.yaml`（Kaptcha 参数）；后台登录验证码由 `BackendLoginCaptchaController` / `ClientCaptchaController` 提供 | 配置文件缺失则启动报 `Kaptcha properties load error` | 无需申请（开箱即用，可微调 `captcha-conf.yaml`） |
| 11 | **数据库与缓存连接** | 运行底座 | 必填 | `spring.datasource`（MySQL JDBC URL/账号/密码）、`spring.redis`（host/port/db）、`spring.session.redis.namespace` | 无法启动或会话/缓存异常 | 客户自有机房 / 云数据库 RDS、Redis |
| 12 | **四套实例端口** | 四行业并行部署 | 必填 | `server.port`（8081/8082/8083/8084）、`server.jetty.max-http-header-size` | 端口冲突则实例起不来 | 运维规划（反向代理 / 防火墙放行） |

## 二、业务种子数据（首次上线需在后台或数据库预置）

| 数据表 | 说明 | 配置入口 | 缺失后果 |
| --- | --- | --- | --- |
| `mt_setting`（导航四宫格 `navigation`） | 会员端首页金刚区 / 四宫格入口 | 后台「系统设置 → 导航配置」或 `mt_setting`（`TYPE` 约定 `navigation`） | 会员端首页入口缺失 |
| `mt_banner` | 首页轮播广告位 | 后台「内容 → Banner」 | 首页无广告展示 |
| `mt_coupon` / `mt_coupon_group` | 优惠券与券分组（含 `send_way`：`backend`/`offline`/`front`） | 后台「营销 → 优惠券」 | 领券中心无可领券，营销能力不可用 |
| `mt_merchant`（商户）、`mt_store`（门店）、`mt_account`（员工账号） | 商户 / 门店 / 后台员工基础档案与归属 | 后台「系统 → 商户 / 门店 / 员工」 | 无法登录后台、无法归属订单与权限 |
| `mt_sms_template` | 短信模板（如 `login-code`、`confirm-coupon`），须 `status=ENABLED` | 后台「消息 → 短信模板」 | 对应短信发送报「模板不存在 / 未启用」 |
| `t_source` / `t_duty` / `t_account`（RBAC） | 后台菜单、角色、账号及权限点 | 后台「系统 → 角色 / 权限」 | 员工无菜单、无操作权限 |

## 三、配置落地优先级建议

1. **P0（不配跑不起来）**：数据库 / Redis 连接（#11）、图片域名与落盘目录（#8/#9）、四套端口（#12）、商户 / 门店 / 员工（#12 业务表）。
2. **P1（核心交易）**：微信支付 V2（#2）、微信公众 / 开放平台 appId（#6）；需微信收款与登录时必配。
3. **P2（增值渠道）**：支付宝（#4）、银联（#5）、微信支付 V3（#3）、对象存储 OSS（#7）。
4. **P3（运营素材）**：短信服务商（#1）、导航 / Banner / 优惠券等种子数据（第二节）。

> 注：所有 `*.yaml` 之外的密钥（如商户级 `mt_merchant`、门店级 `mt_store`、短信级 `mt_setting`）支持在**后台界面**直接维护，便于多租户差异化运营，无需改动配置文件。
